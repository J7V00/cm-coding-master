Quick Start

Follow these steps to start coding

1

Open a folder

Click on Open Folder or drag & drop your project folder.

2

Create a file

Use New File or the plus icon to create files.

3

Write your code

Open index.html and start coding.

4

Run the preview

Press ⌘ + Enter or click Preview to see your result.

5

Use the terminal

Open the terminal to run commands or install packages.
